# ذيبان AI — Firebase + Gemini Image

## ما تم تنفيذه

- Auth وFirestore عبر Firebase.
- توثيق البريد واستعادة كلمة المرور.
- شعار ذيبان في جميع الصفحات.
- استوديو صور منبثق داخل صفحة الخدمات.
- قبول PNG فقط حتى 8MB.
- اختيار نمط جاهز ووصف عربي/إنجليزي للمنتج.
- إرسال الصورة والوصف إلى Gemini Image عبر Firebase AI Logic.
- إخراج 4 صور حقيقية بأنماط مختلفة.
- انتظار يظهر فيه: «ذيبان يضبط لك صورتك...».
- حفظ وتنزيل النتيجة.
- قفل الخدمة للحساب غير المشترك أو بعد التجربة.

## إعداد Firebase AI Logic

1. افتح مشروع `duban-3d487`.
2. اذهب إلى `AI Services → AI Logic`.
3. اختر `Gemini Developer API` وليس `Agent Platform Gemini API`.
4. أكمل `Get started` ووافق على تفعيل APIs المطلوبة.
5. من `Security → App Check` سجّل تطبيق الويب `dhiban`.
6. أثناء الاختبار على رابط Vercel، إذا ظهر خطأ App Check، أكمل تسجيل تطبيق الويب في App Check واستخدم مزود reCAPTCHA المناسب. لا تضع Debug token في مستودع عام.
7. تأكد من أن `dub-beta-ivory.vercel.app` موجود في Authorized domains.

## ملاحظات التكلفة

Firebase AI Logic نفسه ليس اشتراكاً مستقلاً، لكن Gemini Developer API لديه حصة مجانية محدودة. توليد أربع صور يعني أربع طلبات Gemini في كل مرة، وقد تصل الحصة أو تتغير حسب نموذج Google والمنطقة. إذا رفض الطلب بسبب quota، لا تعاود الضغط كثيراً.

## الأمان

لا يوجد Gemini API key داخل ملفات HTML أو JavaScript. Firebase AI Logic يستخدم SDK وGoogleAIBackend. مع ذلك، ضبط App Check والحدود الخلفية مهمان قبل فتح الخدمة للجمهور. الحصة التجريبية في هذه النسخة تمنع التكرار على مستوى الواجهة والمتصفح؛ ولمنع التحايل بشكل كامل نحتاج Cloud Function/خادم موثوق يخصم الرصيد بعد نجاح الطلب.

## النشر

ارفع مجلد `dab` إلى Vercel، ويجب أن يكون `index.html` في الجذر. بعد النشر اختبر بحساب موثق لديه اشتراك أو تجربة واحدة.
