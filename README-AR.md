# تشغيل ذيبان AI بعد الإصلاح

## ما الذي تم إصلاحه؟

- توحيد رابط Supabase إلى رابط المشروع الصحيح: `https://nywanqvgwqfmtvcdpyvl.supabase.co`.
- حذف الخطأ القديم الذي كان يضيف `/rest/v1/profiles_duplicate` إلى رابط عميل Supabase.
- إصلاح أخطاء JavaScript في صفحة الخدمات، خصوصاً النصوص التي كانت ناقصة علامات backtick.
- حماية صفحة `services.html`: أي زائر بلا جلسة يُعاد إلى `login.html`.
- إنشاء الحساب يحفظ البيانات في `auth.users` metadata، ثم ينشئ profile تلقائياً عن طريق Trigger.
- عرض اسم المستخدم والبريد والهاتف ورصيد التجربة بعد تسجيل الدخول.
- التعامل مع حالة تأكيد البريد ورسائل الخطأ بالعربية.
- إيقاف التفعيل الوهمي للاشتراك من المتصفح؛ الاشتراك الحقيقي يحتاج بوابة دفع وEdge Function آمنة.

## الخطوات المطلوبة في Supabase

1. افتح مشروعك في Supabase.
2. ادخل إلى **SQL Editor**.
3. افتح ملف `supabase-setup.sql` وانسخ محتواه كاملاً.
4. اضغط **Run**.
5. من **Authentication > URL Configuration** أضف رابط موقعك في **Site URL**.
6. أضف كذلك رابط إعادة التوجيه، مثل:
   - `https://your-domain.com/login.html`
   - أو رابط الاستضافة المؤقت الذي تستخدمه أثناء التجربة.
7. من **Authentication > Providers > Email** قرر هل تريد تفعيل تأكيد البريد. عند تفعيله، المستخدم يؤكد البريد أولاً ثم يسجل الدخول.

## التشغيل المحلي

من داخل مجلد المشروع شغّل خادماً محلياً، لأن `file://` قد يسبب مشاكل مع Redirect URLs:

```bash
cd dab
python3 -m http.server 5500 --bind 0.0.0.0
```

ثم افتح:

```text
http://localhost:5500/
```

## الملفات المهمة

- `supabase.js`: الاتصال المشترك مع Supabase.
- `signup.html` و`signup.js`: إنشاء الحساب.
- `login.html` و`login.js`: تسجيل الدخول.
- `services.html`: الصفحة المحمية وبيانات الملف الشخصي.
- `supabase-setup.sql`: الجداول والسياسات وTrigger إنشاء profile.

## ملاحظة أمنية

المفتاح الموجود في الواجهة هو publishable/anon key، وظهوره في JavaScript طبيعي مع Supabase عند تفعيل RLS. لا تضع أبداً `service_role` key في الموقع أو ترسله لأي شخص. الرصيد وحالة الاشتراك لا يتم تعديلهما من المتصفح في النسخة الحالية.

## عند ظهور خطأ بعد التسجيل

- إذا ظهر أن البريد غير مؤكد: افتح رسالة البريد واضغط رابط التأكيد.
- إذا لم يظهر profile: تأكد أنك شغلت `supabase-setup.sql` كاملاً، وأن Trigger باسم `on_auth_user_created` موجود.
- إذا فشل رابط التأكيد: أضف رابط الموقع الفعلي في Supabase URL Configuration.
- إذا كان الحساب القديم أُنشئ قبل تشغيل الـTrigger، أنشئ حساباً جديداً للتجربة أو أنشئ profile لذلك المستخدم من SQL Editor.
